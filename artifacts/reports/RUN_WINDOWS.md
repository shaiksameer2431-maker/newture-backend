# NEXA - Windows startup

## Easiest way
Double-click `START-NEXA.bat`.

It opens two command windows (backend and frontend), waits for Vite, and opens the admin dashboard at:

http://localhost:5173/?admin=true

## Manual way
1. Double-click `START-BACKEND.bat` and keep that window open.
2. Double-click `START-FRONTEND.bat` and keep that window open.
3. Open http://localhost:5173/?admin=true

Do not close either terminal while using NEXA.
